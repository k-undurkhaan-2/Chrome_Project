# Step1 - Open Google Chrome's Task Manager
**Tips**: Use shortcut **shift+ESC**

>***Mention: Before next Step, make sure you has already open the tab of armedforces.io***

# Step2 - View Task Manager
Find out the term under the armedforces.io, it's named "https://onlinegames.io/"

**Record the Process ID which at the end of our wanted process.** It's will used in after steps!

# Step3 - Convert the Process ID to hex
Go to google, type "your process ID" to hex.
**Record the hex result return.**

# Step4 - Open Cheat Engine
When you open your Cheat Engine, you will see there is a highlighted symbol on the top left side. 

Click it.

Then you will see a windows named "**Process List**"

*Directly type the hex value* which has been converted just now with using your keyboard

Click "**Open**", the process is matched sucessfully now.

# Step5 - Import the .CT file
Click the sencond button on the top, which has a yellow folder symbol.

Choose our .CT file you download just now.

# Step6 - Back to the website
Start a matching and enter a room, but **before join the match you should make sure that you still has some frag with you**, it's very important for later operation.

# Step7 - Change Values

First join the match, view the lower part of CE, you will see "Active" column, in this line there are some box, click the first box, wait a minute, there will show a red cross in the box.

Choose an effective way to manually decrease your HP value, but no need to much, just a little, no matter with how much but just let that value change

View the lower part of the CE, go to last line which named "current_value"

When you see the value displyed is sames as your value in website, go to "Value" column, click corresponding term, fast enter wanted value. 

>*If you're not sucessfully change your value before the value auto-refreshed, you need repeat the above operations to let your value change again.*

# **Tips for value choosen**:
***Don't set an extreme value, if after your changed your value, the current HP value displayed as "+Inf" mean that's a invalid value, it's equivalent to 0!***
