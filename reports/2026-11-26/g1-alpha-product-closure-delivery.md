internal full selection. Full construction requires the existing guarded
execution dependency before CE API acquisition, so it cannot obtain NORMAL's

FoundList index through guarded reads/mapping checks; AC6 invokes AC5's complete

comparator, duplicate/excluded handling and recommendation algorithms are reused.

is substituted. Existing strict 128/128 qualification limits reject excess
population before scoring; they are not raised.

ID2 now separates operation API success, actual readback and monitored validity.
An operation returning true does not imply verified readback. Failure, mismatch
and exceptions retain distinct outcomes. ALPHA_STOP_ONLY still stops and cleans
up on observable invalidity/terminal errors; only deliberate Start after confirmed
cleanup can begin another run. Finite numeric drift remains allowed by the
existing structural monitor; no semantic-liveness or freeze algorithm was added.

The actual positive bridge test uses the existing QSG synthetic table and
independent bytearray facilities. It does **not** execute a successful native
standard ID1. The ordinary target branch reaches admission with the configured
parameters and rejects there. `config_application=NOT_APPLIED`,
`acquisition_complete=false`, native operation/readback NOT_RUN and
`acquisition_evidence=NOT_ESTABLISHED` remain truthful on that branch.

different from independently established acquisition completeness.
