data and safe PID 0 / writes false defaults. Ordinary ID1 reads the bound sibling
config and passes original target parameters to the existing adapter's full
admission boundary. A fixed synthetic selector is no longer the only config route.

supplied-population scoring through guarded reads and exact source/count/identity

unconfirmed readback and monitored validity. It remains inert. Alpha retains

Engineering and strict qualification retain their existing separate contracts.

## Mandatory product limitations

**The normal standard product cannot yet execute its complete authorized target
workflow.** QSG's constructor and recorder support synthetic provenance only.
Native identity/attachment, complete acquisition, operation authority and verified
native readback are not established. Standard admission therefore refuses
QSG_NATIVE_BACKEND_NOT_QUALIFIED before acquiring CE/target APIs.

Delivery identifies a blocked standard CT with original safe config, not a
synthetic-only substitute. The shared bridge's synthetic operation test does not
establish native ID1 acceptance. P01-P07 actual authorized native integration and
P09 usable native standard delivery remain unestablished. P08/P10 have scoped
implementation and compatibility evidence. There is no blanket product PASS.

Native completeness, semantic identity, CE-host behavior, hard timeout,
cancellation latency, process peak, UI SLA and capacity remain NOT_RUN,
NOT_ESTABLISHED or unknown. No limit is increased. Strict 128/128 qualification
does not become a qualified arbitrary-size native full service.
