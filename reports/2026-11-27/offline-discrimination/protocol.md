## Initial hypotheses, before new alternative outcomes

Test empirical frequency using the seven existing structural observations.
Identity, input order, session identity and reference labels are not features.
Frequencies must be invariant to bijective value renaming within each field.

Compare mean normalized self-information of (a) individual field values,
(b) all 21 field-value pairs, and (c) complete observation tuples. Counts
include the candidate and use additive-one smoothing. Normalize by singleton
self-information so the supplement is in [0,1]. Missing values are explicit
categories, never imputed words. Retain the full baseline score and compare
supplement amplitudes 1, 3 and 6: one score unit and the existing mild/medium
clone penalties. This is a finite nine-variant research comparison, not nine
independent samples. Report every outcome and reject ineffective variants.
